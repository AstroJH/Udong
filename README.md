# Udong

**Long-term scientific computing infrastructure for SDSS-IV MaNGA data science and AGN/galaxy research.**

Udong is a from-scratch, gradually-extensible research codebase for working
with MaNGA integral-field-unit (IFU) data.  The near-term science goal is
**NLSy1 AGN feedback**, but this repository deliberately focuses first on a
reliable, clearly-designed, well-tested *foundation* so that future science
modules (emission-line measurements, kinematics, BPT diagnostics, outflow
diagnostics, sample selection, catalog cross-matching, ...) can be added
naturally.

## About the Name

Udong is named after the Chinese blackbird (乌鸫, Turdus merula 🐦‍⬛).
